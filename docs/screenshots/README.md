## How to capture

1. Open `Fed-Spend-Analytics.pbip` in Power BI Desktop and refresh it with the prepared data.
2. Leave each page at its saved default filters (Agency Performance opens on FY2025; the other pages show all
   fiscal years). Clear any selections made while exploring.
3. Collapse the Filters, Visualizations and Data panes and use **View → Fit to page**, so the full 1280 × 720 page is
   visible.
4. Capture only the report canvas (for example with Windows Snipping Tool, `Win + Shift + S`). Leave out the title bar,
   file path, ribbon, account name and any other application chrome.
5. Save as PNG with the file names above, at least 1280 px wide, ideally under 1 MB each.
6. Before committing, check each image for anything personal or unintended (notifications, other windows, file paths).
